# MiaCode Mobile 当前功能状态

更新日期：2026-10-09。分支：`Miacode_Mobile`。迁移参考：v2 `c190bb2c138cf61032dd7ac97ec41027da4bb40d`。本次提交保存当前开发成果，P5 用户验收和全页面相似度验收继续进行。

## 已接入的主要功能

| 范围 | 当前实现 |
| --- | --- |
| 谱面编辑 | 复用 v2 编辑器、高亮、补全、查找替换、书签、多难度、元数据、整理及变换；保存与恢复由 Android 私有工程及 SAF 桥管理。 |
| 校验与辅助 | 共享解析、语法诊断、动态无理分析及定位；校准页的 BPM/偏移检测和测试谱试听已接入。 |
| 时间轴与预览 | 共享波形、对象时间轴、播放线、缩放、跟随、实时 QSG 场景、PV、皮肤及音效；导出试听支持负时间片头。 |
| 视频与音频导出 | 本机 MP4/WAV、单曲、选区与批量任务；片头、预备计数拍、渲染设置、质量和体积预设，以及 SAF 输出发布。 |
| 封面 | 共享画板、字体、背景、图片/文本图层、谱面帧、JPG/透明 PNG、预设及多难度批量封面。 |
| 安卓工作台 | 强制横屏、按内容安全区和屏幕比例适配、分隔条布局与设置持久化、语言切换、音频/预览设置、ZIP 打包及后台导出开关。 |

“已接入”描述代码和已记录消费者验证，完整设备矩阵的产品验收尚未完成。详细证据见 [实现与验收记录](ANDROID_P5_WORKLOG_ZH.md)。2026-10-03 上传审阅中的“未接入批量导出”等条目是当时的历史状态，以本文为当前状态入口。

## 实现与一致性仍需补齐

| 项目 | 剩余工作及当前依据 |
| --- | --- |
| 播放中编辑的快照 | Android `MobilePreview::refreshDocument()` 会更新正在使用的对象；还需对齐 v2 正常播放时的冻结快照及停止后应用修改的规则。 |
| 校准页退出位置 | 当前 `MobileLatency::setOnPage(false)` 清理测试谱后调用停止；需要对齐 v2 的退出位置/原谱面恢复规则，不能仅以已恢复对象数量判定一致。 |
| 时间轴与光标导航 | 继续核对 v2 的 R 快捷键、光标跟随、聚焦与导航状态组合；现有 seek、停止回起点和拖动后保持暂停已有验证，不能覆盖所有组合。 |
| 音频长度统一 | 单曲预览/导出优先使用波形解码长度；Android 批量准备仍使用 `MediaMetadataRetriever` 元数据。需统一单曲与批量的长度依据，并核对两端解码采样差异。《白金ディスコ》当前 Android 为 103.183 秒，v2 为 103.171678 秒，约差 11.3 毫秒。 |
| 自定义片头音源边界 | 已接入选择、解码和试听；超过 5.816667 秒的自定义声音跨零点连续性，以及大量计数拍的资源上限仍需完成核对与必要修正。当前片头传输在零点重启正文音效。 |
| 中断后的恢复体验 | 导出失败会保留私有完整文件，但系统回收后的视频/批量任务恢复、重新发布入口，以及 SAF 提供方留下不完整输出时的清理和提示仍需完善。 |
| UI 细节与封面配对 | 当前普通 APK 导出输出页同尺寸人工审阅为 91 分；字体字重、路径显示、表单偏移和背景透出仍有差异。封面局部叠加效果、参考客户端边界及其他主要页面的统一配对仍待完成。分数不是像素一致率，全页面 90% 尚未通过。 |
| 发布准备 | 当前 APK 使用测试签名；正式发布密钥、APK 同签名升级及正式发布验收仍待完成。 |
| v2 最新更新 | 当前仍按既有迁移参考实现。最新 v2 差异同步按用户既定安排，在 P5 用户验收完成后执行；本次开发快照提交不等于验收通过。 |

## 已实现但尚未完成的设备验收

- 物理 ARM64 手机和平板，最低 Android 12，Adreno/Mali GPU，低内存设备，以及真实 16 KB 页面设备；目前的原生运行证据主要来自 Android 14 模拟器的 ARM 转译环境。
- 软键盘/中文 IME、长文本选择与粘贴、外接键盘、安全区及各屏幕比例的完整操作矩阵。
- 最新候选的长时间后台/锁屏导出、通知取消、权限撤回、应用切换、系统回收及恢复；旧 APK 的后台证据不替代最新候选验证。
- 10 档分辨率、30/60/120 FPS 和 AAC 档位的真实编码能力及压力测试。设备提供的编码能力不能仅由选项列表推断。
- 长曲、大批量、多层封面、PV 的内存、温升、速度、音画同步和持续拖拽稳定性。宿主界面回归曾在与测试套件并行运行时暂停；独立运行两次通过，失败原因和长期稳定性仍待核对。
- 不同 SAF 提供方、只读来源、授权撤回、空间不足和安装升级的完整失败矩阵。

P5 总体状态：未验收。当前源码的构建和自动测试结果见 [2026-10-09 提交审阅](ANDROID_UPLOAD_REVIEW_20261009_ZH.md)，界面评分范围见 [UI 配对记录](ANDROID_UI_PAIRING_ZH.md)。
