# Net 下载页面目标与验收条件

## 目标

下载页面作为 v2 独立标签页，提供从查询、选择、下载到在线预览的完整操作流程。v1 截图用于确定信息层级和操作顺序，v1 功能源码与迁移文档用于确定业务行为；界面使用 v2 的主题、公共控件和服务。

## 页面与交互

- 顶部组织用户 ID、Tag、歌曲名、日期范围、大小写匹配、排序、连接检测、输出目录、PV 和 ZIP 设置。
- 结果使用表格，展示序号、选择、标题、曲师、谱师、等级、上传时间、任务状态及在线预览操作。
- 底部提供查询结果与任务摘要、全选、取消全选、日志、进度、下载或取消、暂停恢复和关闭标签页。
- 页面宽度跟随标签页可用区域，筛选组和底部操作随宽度换行；内容高度超过可视区域时提供纵向滚动。表格提供独立横向滚动，纵向滚动条固定在表格可视区右侧。筛选控件使用清晰标签和日期选择器。
- 重复打开复用标签页；任务状态由共享服务持有，切换或关闭标签页保留任务。

## 下载

- 查询参数按 AND 组合；日期按本地时区包含首尾日期；查询结果按所选字段排序。
- 下载选中谱面的音频、封面、谱面及可选 PV；PV 的 404 记录为资源缺席。
- 任务逐项展示资源阶段、字节进度、成功、失败和取消状态；资源失败按规定重试，访问阻断暂停队列。
- 每个谱面通过独立暂存目录完成资源与 manifest，校验后发布文件夹。输出冲突按明确策略处理。
- ZIP 按 manifest 中的已接受资源生成，包含所选 PV。显式声明的空谱面使用统一验收规则。
- 取消保留成功输出；恢复跳过成功项目。输出目录复用 `app.last_net_batch_output_dir` 偏好字段。

## 在线预览

- 行操作准备资源缓存，返回预览引用，通过独立打开操作进入文档服务。
- 缓存结合远端版本及有效期复用，资源缺席参与缓存完整性判定。
- 打开操作检查工作区、文档打开代次和 revision，并使用现有离开文档决策。
- 预览文档标记为 `net_preview`，复用谱面解析、编辑、播放、音频、时间轴和舞台预览。
- 缓存文档参与编辑；保存进入另存为，本地副本恢复 `local` 来源。历史、会话恢复、自动保存及崩溃恢复使用来源标记判定。

## 接口

业务通过 `NetService`、`JobRegistry` 与规范化操作目录组织；公开请求使用 provider、chart、job、preview 和 directory grant 引用。宿主文件路径经内部端口传递。

本阶段围绕 `net.downloads.create`、`net.previews.prepare`、`net.previews.open`、`net.previews.release` 及查询、任务接口完成下载与在线预览的调用链。接口契约、生成产物与实现状态同步更新。

## 验证

使用本地可控 HTTP 响应验证资源下载、PV 缺席、PV 与 ZIP、空谱面、重试、阻断、取消、发布冲突及预览缓存；文档测试验证来源和另存为；使用 `build-devtools` Release 构建验证 C++、QML、翻译与模块分层。
