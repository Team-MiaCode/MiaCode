# Net 上传页面目标与验收条件

上传页面作为独立标签页，按 v1 图示的信息层级组织账户、目录、队列和任务操作，复用 v2 的公共控件、主题及 Net 服务。

- 顶部账户区提供用户名、密码和账户记忆设置；目录区提供谱面根目录、浏览和“添加到队列”。两区随标签页宽度调整行数。
- 中部表格提供序号、谱面文件夹、上传文件清单、路径和任务状态。长路径可查看全文，队列支持选择与排序。
- 页面宽度跟随可用区域，底部操作随宽度换行；高度由内容与可视区域共同确定，提供纵向滚动。表格提供独立横向滚动，纵向滚动条固定在可视区右侧。
- 底部提供加入数量与队列摘要、移除所选、清空队列、上传进度、上传或取消及关闭标签页。
- 目录扫描识别 `maidata.txt`、音频、封面及可选 PV，复用当前扫描规则；重复加入复用目录身份，保持用户指定顺序。
- 扫描结果记录资源缺失、文件读取、目录权限及文件变化的原因，页面日志提供对应目录与详情。
- 登录与上传使用账户隔离的网络会话；密码显示为遮蔽文本，凭据经账户服务和平台安全存储管理。
- 上传任务按目录展示当前阶段及结果。HTTP 413、422、429、访问阻断和响应丢失按迁移契约区分处理。
- 队列、账户和任务归服务持有，标签页负责展示与操作；切换或关闭标签页保留任务。
- 功能验收依据 v1 上传源码和 `NET_MIGRATION_TEST_CHECKLIST_ZH.md`；图示提供布局方向。

账户调用 `net.accounts.login/list/logout`，目录扫描调用 `net.uploads.scan`，队列提交调用 `net.uploads.create`。扫描追加携带 `uploadPlanRef` 与当前 `retainedItemIds`，移除的目录可通过加入操作生成新材料引用。文件路径通过宿主端口解析，公共请求保留不透明引用。

上传使用经过大小、修改时间和 SHA-256 校验的文件副本；重试使用同一副本。提供者共用串行上传、5 秒间隔及登录/上传限流时钟。响应丢失记录为结果待确认；队列保留该状态供用户核对。Windows 账户记忆使用 Credential Manager。

旧 `app.net_upload_*` 凭据通过安全保存和回读核验迁移，密码键经偏好仓库原子写入清除；迁移失败返回诊断并保留磁盘来源。任务项目以 `retryAt` 提供等待截止时间，界面显示上传间隔和限流倒计时。

账户、扫描和上传验证采用源码核对、Schema 检查与 Release 编译，功能运行验收由用户执行。

队列支持多行选择，通过序号栏拖动或上下移动调整顺序。失败批次提供重试入口，新任务引用父任务并继承项目身份；成功和结果待确认项目保留状态。上传日志复用 DebugLog 的 NetUpload 通道，界面提供日志路径与项目错误详情。
